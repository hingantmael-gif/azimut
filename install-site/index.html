Azimut

Application Android native

Une vraie app (icône logo Azimut sur l’écran d’accueil) — pas un site web.

Tu es sur un PC. Un fichier Android (.apk) ne s’installe pas sous Windows (Adobe / Firefox / Lecteur ne serviront à rien).

Scanne le QR avec ton téléphone Android, ou envoie-toi ce lien, puis appuie sur Installer l’application depuis le téléphone.
  1. Appuie sur Installer l’application (ci-dessous).
  2. Quand le téléchargement est fini, ouvre la notification ou le dossier Téléchargements → azimut.apk.
  3. Si Android demande, autorise l’installation (sources inconnues / Chrome).
  4. Appuie sur Installer — l’icône logo Azimut apparaît sur l’écran d’accueil.

Page web = téléchargement uniquement
Application = APK Android autonome
