Azimut

Coaching multi-sport — ouvre l’app, ou installe-la sur cet appareil (icône logo Azimut, comme BTP Pro).

Scanne pour ouvrir cette page sur un téléphone

Ouvrir l’application
iPhone / iPad
  1. Ouvre cette page dans Safari
  2. Appuie sur Partager
  3. Choisis Sur l’écran d’accueil
Chrome / Edge
  1. Clique d’abord Ouvrir l’application une fois
  2. Reviens ici, puis menu ⋮ → Installer Azimut
  3. Ou icône ⊕ / Installer dans la barre d’adresse
