# Référence modèle Strava (interne)

> Document de travail pour aligner navigation, paramètres et monétisation.
> Pas une copie de marque — structure fonctionnelle inspirée du leader marché.

## Navigation principale (5 onglets)

| Onglet | Rôle |
|--------|------|
| **Accueil** | Fil d’activité (amis, clubs, kudos) |
| **Cartes** | Cartes, segments, exploration |
| **Enregistrer (+)** | Démarrer une activité (GPS / manuel) |
| **Groupes** | Clubs, défis, classements |
| **Vous** | Profil, stats, accès paramètres (⚙) |

## Paramètres (structure Strava)

### Profil & sport
- Mon profil (photo, bio, ville, sexe, poids, taille)
- Mes objectifs (course, distance, heures/semaine)
- Ma forme et entraînement (Fitness, fatigue, pics — Premium)

### Abonnement
- **Gratuit** : fil limité, sync basique, stats essentielles, enregistrement activité
- **Premium** (~8–12 €/mois ou ~60–80 €/an) : plans d’entraînement, métriques avancées, segments live, beacon/sécurité, analyse performance, routes, filtres feed, sans pub

Modèle freemium Strava :
1. Acquisition gratuite (enregistrer + social)
2. Conversion Premium via métriques avancées + coaching + sécurité
3. Rétention via clubs, kudos, défis, streaks

### Applications et appareils connectés
- Garmin, Apple Watch, Wahoo, etc.
- Statut : **Connecté** / **Non connecté**
- Sync auto des activités et parfois santé (HRV, sommeil selon partenaire)

### Confidentialité
- Visibilité activités (Tout le monde / Abonnés / Seulement moi)
- Zones de confidentialité (masquer départ/arrivée domicile)
- Masquer FC, poids, carte

### Données
- Export données (GDPR)
- Autorisations app (localisation, santé, notifications)

### Affichage
- Unités (km/mi, kg/lbs)
- Thème clair/sombre
- Langue

### Notifications & e-mail
- Kudos, commentaires, activités amis
- Rappels entraînement, marketing (opt-in)

### Compte
- E-mail, mot de passe, 2FA
- Déconnexion, suppression compte
